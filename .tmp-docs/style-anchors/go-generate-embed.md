# Go Generate Embed Pattern

## Overview

Uses `go:generate` to copy and transform external content (SKILL.md files) into a generated Go source file at build time. This avoids `embed.FS` path restrictions (can't use `../`) while keeping content version-controlled and in sync with the binary.

## Context

Go's `//go:embed` directive cannot reference parent directories (`../skills/`). The `go:generate` approach copies the skill content into the `prompt/` package directory as a generated `.go` file, which is then compiled into the binary.

## Code Example

### The generate directive (`prompt/embed.go`):

```go
package prompt

//go:generate go run gen_prompts.go

// content maps prompt name to its stripped SKILL.md body.
// Populated by content_generated.go (generated by go:generate).
var content map[string]string
```

### The generator (`prompt/gen_prompts.go`):

```go
//go:build ignore

package main

import (
    "bytes"
    "fmt"
    "os"
    "path/filepath"
    "sort"
    "strings"
)

func main() {
    skillsDir := filepath.Join("..", "skills")

    entries, err := os.ReadDir(skillsDir)
    if err != nil {
        fmt.Fprintf(os.Stderr, "failed to read skills dir: %v\n", err)
        os.Exit(1)
    }

    // Build the map literal
    var buf bytes.Buffer
    buf.WriteString("// Code generated by gen_prompts.go. DO NOT EDIT.\n")
    buf.WriteString("//go:build !ignore_autogenerated\n\n")
    buf.WriteString("package prompt\n\n")
    buf.WriteString("func init() {\n")
    buf.WriteString("\tcontent = map[string]string{\n")

    var names []string
    for _, entry := range entries {
        if !entry.IsDir() {
            continue
        }
        skillFile := filepath.Join(skillsDir, entry.Name(), "SKILL.md")
        data, err := os.ReadFile(skillFile)
        if err != nil {
            continue // skip directories without SKILL.md
        }
        names = append(names, entry.Name())
    }

    sort.Strings(names)

    for _, name := range names {
        skillFile := filepath.Join(skillsDir, name, "SKILL.md")
        data, _ := os.ReadFile(skillFile)
        body := stripFrontmatter(string(data))
        buf.WriteString(fmt.Sprintf("\t\t%q: %q,\n", name, body))
    }

    buf.WriteString("\t}\n}\n")

    if err := os.WriteFile("content_generated.go", buf.Bytes(), 0644); err != nil {
        fmt.Fprintf(os.Stderr, "failed to write generated file: %v\n", err)
        os.Exit(1)
    }

    fmt.Printf("Generated content_generated.go with %d prompts\n", len(names))
}
```

## What This Demonstrates

- `//go:build ignore` tag on the generator so it's not compiled into the package
- `//go:generate go run gen_prompts.go` directive for `go generate` discovery
- Generated file has `//go:build !ignore_autogenerated` guard
- Content populated via `init()` function in generated file
- Sorted output for deterministic diffs
- Generator validates inputs and exits with code 1 on failure

## When to Use

- When `embed.FS` can't reach the content (parent directory restriction)
- When content needs transformation before embedding (e.g., stripping frontmatter)
- When content should be version-controlled as a generated artifact

## Pattern Requirements

- ✓ Generator MUST have `//go:build ignore` tag
- ✓ Generated file MUST have `// Code generated by ... DO NOT EDIT.` header
- ✓ Generated file MUST have `//go:build !ignore_autogenerated` build tag
- ✓ Use `init()` function in generated file to populate package-level var
- ✓ Sort entries alphabetically for deterministic generated output
- ✓ Generator MUST exit with code 1 on any failure
- ✓ Generator MUST print success message with count
- ✓ Generated file MUST be committed to git (not in .gitignore)

## Common Mistakes to Avoid

- ❌ Forgetting `//go:build ignore` on the generator — it gets compiled into the package twice
- ❌ Adding generated file to `.gitignore` — breaks builds without go:generate
- ❌ Using `embed.FS` with `../` paths — compile error
- ❌ Not sorting entries — every generate produces different diff
- ❌ Writing to files outside the package directory — violates Go build conventions
