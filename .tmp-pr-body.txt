## Summary
Implements token-efficient planning workflow via on-demand prompt delivery:
- **New command:** `sherpy prompt` - Outputs skill instructions for 12 planning pipeline steps
- **New skill:** `sherpy-cli-planner` - Orchestrates planning via CLI prompt commands
- **80K vs 720K tokens:** Users get prompts on-demand instead of installing 16+ skills

## Installation
Users must build the binary locally (not committed to repo):
```bash
# Clone and build
git clone <repo-url>
cd sherpy
go build -o sherpy .

# Verify installation
./sherpy prompt --list
```

## Key Design Decisions
1. **Frontmatter stripping** - Removes `---\nname: ...\n---` blocks from skill content
2. **go:generate** - Embeds skills at build time (no runtime file I/O)
3. **Registry pattern** - Map-based prompt lookup with thread-safe access
4. **Integration tests** - Verify compiled binary vs. test harness
5. **Binary not committed** - Users build locally to avoid repo bloat

## Token Efficiency Impact
- **Before:** User installs 16 skills → 720K tokens in context
- **After:** CLI provides prompts on-demand → 80K total (90% reduction)
